Tiny Pomodoro XFCE

Small floating Pomodoro and countdown timer for Linux X11 desktops, including Xubuntu/XFCE and GNOME on X11.

GTK XFCE Xubuntu Pomodoro APT

Install with APT

curl -fsSL https://guarinogio.github.io/tiny-pomodoro-xfce-apt/public.key \
  | sudo gpg --dearmor --yes -o /usr/share/keyrings/tiny-pomodoro-xfce.gpg

echo "deb [arch=all signed-by=/usr/share/keyrings/tiny-pomodoro-xfce.gpg] https://guarinogio.github.io/tiny-pomodoro-xfce-apt stable main" \
  | sudo tee /etc/apt/sources.list.d/tiny-pomodoro-xfce.list

sudo apt update
sudo apt install tiny-pomodoro-xfce

Run

tiny-pomodoro

Features

  • Pomodoro and countdown timer modes
  • Small floating always-on-top window
  • System notifications and optional sound
  • XFCE and GNOME dark mode detection
  • Timer shutdown option with cancellation
  • Installable Debian package and public APT repository
